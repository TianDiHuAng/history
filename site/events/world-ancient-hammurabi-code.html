汉谟拉比与《汉谟拉比法典》

中国 / 世界 / 古代文明（两河·埃及·印度河·爱琴） / 事件

一、时间、地点、主要人物

时间：约前1754年（据巴比伦中年代说，汉谟拉比在位约前1792—前1750年，法典石碑刻成通常系于其在位晚期（约前1754年前后）。）

地点：巴比伦（石碑1901—1902年出土于苏萨，今存巴黎卢浮宫）

主要人物：汉谟拉比

二、背景与起因

汉谟拉比通过联盟与征伐统一两河南部（"巴比伦尼亚"），为宣示统治正当性，以阿卡德语刻成法典石碑，立于神庙（后为埃兰人掠至苏萨）。

三、经过（按时间顺序）

  1. 汉谟拉比在位初期与拉尔萨、马里等结盟周旋，逐步兼并。
  2. 统一两河大部后颁布法典：序言宣示受神命护弱，正文282条，结语诅咒毁碑者。
  3. 条文涵盖买卖、租赁、家庭、雇佣、医疗、航运与等级（自由民/穆什凯努/奴隶）差等处罚。
  4. 石碑约前1155年前后被埃兰人携往苏萨，1901—1902年由法国考古队发现，现存卢浮宫。

四、结果与影响

现存最完整的大型古代成文法体系之一；其"同态复仇"（以眼还眼）条款成为法律史经典研究对象；法典树立"正义之王"的王权形象，被后世近东王权文本反复引用。

五、史料来源与史学争议

争议：法典的实际效力

  • 传统法律史叙事：视为"最早成文法典"，推断其实际规范社会生活。
  • 现代亚述学研究：出土判决文书与法典条文常不一致，学界讨论法典更多是王权宣示与教学文本，实际司法以本地惯例为主。

争议："人身等级与同态复仇"的解释

  • 等级差序说：伤害自由民与伤害穆什凯努、奴隶的罚则不同，体现身份法特征。
  • 经济功能说：部分学者强调条文多为个案判决的汇编性质，不是完整立法体系。
