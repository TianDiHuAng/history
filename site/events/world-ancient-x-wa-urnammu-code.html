乌尔第三王朝与《乌尔纳姆法典》

世界 / 古代文明（两河·埃及·印度河·爱琴） / 延伸事件

时间

约前2112年—约前2004年（乌尔纳姆建乌尔第三王朝约前2112年（近东中年代说，通说）；王朝终于约前2004年（埃兰人攻灭）。"约"即年代说差异（长/中/短年代说并存）。）

说明

乌尔纳姆颁布的《乌尔纳姆法典》残片为现存最早的成文法典（早于汉谟拉比约三百年）：以"使正义不致被强力所毁灭"开篇，罚金刑多于同态复仇。乌尔第三王朝复兴苏美尔语文化（乌尔大塔庙存世），其官僚文书为苏美尔语的最后辉煌期。
